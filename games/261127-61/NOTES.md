# キリンの まくらは どこ？（261127-61）

夕暮れのサバンナ。太陽をゆっくり下げると、成獣のメスのアミメキリンが平らな短い草の休み場所へ歩き、前脚から折って伏せ、
首を立てて休み、やがて首を後ろへ回して **自分の腰（後躯・後脚の上）を枕にして** 眠る。手前の草を払うと隙間から覗け、
長く払うと観察位置が横へ移って、頭を何に載せたのか・脚がどこへ入ったのかを別の側から確かめられる。月を下げると朝になり、
キリンは起きて立ち去り、露の消えた寝跡と足跡が残る。足跡をたどって選んだ側から、次の夕暮れ（次のおやすみ）を迎える。

`format=toy_sandbox` / `style_id=realistic3d` / `subject=free`。文字・数字・台詞なし。指1本。開始メニューなし。

## 遊びの流れ（体験の核）
| 触る | 変わる | 次に試したくなること |
|---|---|---|
| 太陽（タップ／下へなぞる） | タップした瞬間に太陽が少し下がり影が伸びる。下げた量だけ日が沈み、影が連続して伸びる。低くなるとキリンが自分で平地を選んで伏せる | 途中で止めて「首を立てて休む姿」と、地平線まで下げた後の「腰を枕に眠る姿」を見比べる |
| 手前の草一房（短く払う） | 根元を支点に茎がしなり、隙間から脚や頭がのぞく。離すと減衰しながら戻って再び隠れる | 同じ方向へ長く払う |
| 草（同じ方向へ長く払う） | 指に続いて観察位置が横へ移り、次の草の切れ目で止まる（位置補正）。草が戻っても位置は残る | 反対側へ回って、頭と後脚の重なりが奥行きで分かれるのを見る |
| 草の音（払う強さ・速さ） | 起きている個体（立位・首を上げた伏臥）は耳を音へ向け、強いと頭も向ける。腰を枕に眠る個体は小さな音では耳が少し動くだけ、強く続くと穏やかに頭を上げる（脚は畳んだまま） | 開けた場所から小さく払い、「伏せている」と「眠っている」の違いを比べる |
| 月（下へなぞる） | 夜が進み朝になる。キリンは首を後ろへ振り、後躯から先に立ち、前脚を片方ずつ伸ばして立って立ち去る | 立ち去った場所をのぞく。足跡をたどって横へ移り、次に見る側を選ぶ |

無操作約4秒で、今の誘い（太陽・草一房・月のどれか1つ）を指のお手本が一度だけ実演し、触れると消える。誘いの対象は光る（太陽・月は脈打つ光輪、
草は穂がほのかに明るくなり弾む）。伏せる・枕に頭を預ける・立ち上がる等の重要動作中は誘導しない。関係ない場所に触れると、その場の草くず・土粒が少し舞うだけ。

## 発見リスト（完成条件）と確認記録
「操作・条件 → 観察結果 → 次の試し方」。確認方法の区分は下の「検証」を参照。

1. **太陽を地平線へ下げる** → 主役が平地を選び、前脚の手根（前ひざ）から着き、後躯を下ろして胸で伏せる。首はまだ立っている（反芻）。
   日が沈むと首を後ろへ回し、後躯（腰の脇〜後脚の上）に頭を預ける。
   → 次：途中（約2〜3°）で太陽を止めると首を上げた伏臥のまま。見比べる。
   - 自動通し試験（390×844）：最初のタップ 0.5 s → 伏臥完了 21.9 s → 日没 29.6 s → 枕寝 33 s（1分以内）。太陽 1.8° で止めた間は `rest`（首を上げた伏臥）のまま枕寝に入らないことを確認。
2. **草を短くゆっくり払って離す** → 茎が根元からしなって隙間から脚や頭がのぞき、離すと減衰振動しながら戻って再び隠れる。長く横へ払うと隣の切れ目へ移り、払い続けなくても見通しが保たれる。
   - 自動通し試験：覗き用の草一房（毎夕、観察線上に少しずらして置き直す）を払う → `discover:peek`。長い払い → `walk-through` → `move` → 次の観察位置に停止（φ 0→−24→−48）。押さえた状態／離した直後の画面を撮影して描画確認。
3. **頭を預けた姿の横へ視点を移す** → 正面では頭が胴の向こうへ回って後脚と重なって見えるが、枕側へ回ると首の弧と腰に載った頭が奥行きで分かれる。反対側では胸の下に畳んだ前脚と、体側へ出した後脚が全身像で見える。
   - 自動通し試験：`discover:pillow-side`（81 s）、`discover:legs-side`（116 s）。各観察位置（φ=0, ±24, ±48, ±72）から描画を撮影して確認。
4. **異なる休息状態で草を払う** → 首を上げて伏せている時は耳だけが音へ向く（`discover:ears-while-lying`, 24.8 s）。枕寝中は小さく払っても耳が少し動くだけ、強く続けると頭が上がるが脚は畳まれたまま（`discover:wake-by-sound`, 56 s）。覚醒は失敗扱いにせず、しばらくして再び休む。
   - 夜を無操作で流すと、伏臥（首上げ）・枕寝・覚醒・再休息・一度立って少し移動してから伏せ直す、を行き来する（同じ寝姿で夜通しにならない）ことを状態記録で確認。
5. **月を下げて朝にし、立ち去った場所をのぞく** → 観察者が切れ目から一歩踏み込み、立ち上がって見下ろす。朝露で銀色に光る草の中に、胸・脚・腰の形で露の落ちた暗い寝跡が残り、倒れた草は低い朝日で明るく光る。蹄の跡（二つに割れた蹄形）が今いる場所（アカシアの木）まで続く。足跡をたどって横へ移ると、その側が次の夕暮れの観察側になる。
   - 自動通し試験：月を下げる → `moonset`（228 s）→ `rose`（238 s）→ `discover:trace`（242 s）→ 横へ移動 → `day` → `dusk`（2周目、移動した側から開始）。寝跡は姿勢の実際の接地点（スキニング後の頂点）から作る。

## 生態の根拠と扱い
- 参照指定：ARTIS（Reticulated giraffe）と野生研究（PMC7083675, Burger et al. 2020, *Nightly selection of resting sites and group behavior reveal antipredator strategies in giraffe*）。
  **この制作環境からは両ページとも取得できなかった**（ネットワーク制限で DNS 解決不可）。検索結果の要約と以下の二次情報で確認した範囲に留め、断定的な数値は使っていない。
  - 動物園での行動睡眠研究（Tobler & Schwierin 1996）の要約：逆説睡眠は頭を後躯（croup）に載せる独特の姿勢で認められ、エピソードは短い（数分）。頭は後脚の脇か地面に置かれる。
  - 伏せ方：後脚を少し開き、首をほぼ水平に下げて地面を見て、前脚を慎重に置き、前ひざ（手根）に落ちてから後躯を下ろし、胸骨で伏せ、片方の後脚を体の左右どちらかへ出す（観察論文の要約・Snapshot Serengeti の観察者記述）。
  - 立ち方：資料間で記述に差があったため、首を振って重心を移し、**後躯を先に**上げて前ひざ立ちから前脚を伸ばす、反芻類で一般的な順序で固定した（首の振りの利用は複数資料で一致）。
  - 伏せたまま反芻する（首を上げた伏臥＝必ずしも睡眠ではない）。
- 行わないこと：伏臥を常に睡眠と扱う／固定の見張り役制度／年齢での眠り方の二分／総睡眠時間の断定。背景の個体は主役と独立に、ときに伏せ・ときに立つ（休息が入れ替わることがあるが規則ではない）。
- 休み場所は平らで短い草の開けた場所（指定どおり）。休息候補・観察側・草の重なり・光の向き・寝る側（左右どちらの腰を枕にするか）は毎回少し変わる。発見不能になる乱数は使わない（月・太陽は必ず観察範囲から届く位置に来る）。

## 主役の造形（写実3D）
- 成獣メスのアミメキリン：符号付き距離関数（楕円体・丸錐の滑らかな合成）で解剖学的な比率の体を作り、`tools/bake.mjs` で Surface Nets によりメッシュ化
  （主役 約4.1万頂点・8.3万三角形、背景個体は約0.8万頂点の低解像度版）。頂点ごとに SDF 勾配の法線、AO、毛色の領域（斑の量・大きさ・淡色・暗色）、39本の骨へのスキンウェイトを焼き込み、
  量子化＋deflate で HTML に埋め込み、実行時に展開する。
- 体：高いき甲から後ろへ下がる背線、長い頸（5骨で連続的に曲がる）、手根・飛節の二重関節（深い折り畳みでの潰れを抑える）、割れた蹄、尾と黒い房毛。
- 頭：一対のオシコーン（メスなので先端に黒い毛房）、額の小さな隆起、左右の耳（内側が淡色の葉形）、大きな黒い眼と上下まぶた・まつげ（眠ると閉じる）、
  反芻であごが動く。短く直立したたてがみ。
- 毛色：褐色の不規則多角形斑と細いクリーム色の網（3D ボロノイの境界距離で線幅を一定に）。斑は体・脚・顔で大きさが違い、膝から下は斑のない淡色。
  個体ごとに斑の配置が異なる（シード）。短毛の質感（光沢・逆光のふち明かり）。
- 姿勢は「関節の目標点」と「首のベジェ曲線（首の長さを保つ弧長合わせ）」から骨の回転を解く。体の一番低い部分を常に地面に接地させる（瞬間起立・宙浮きを防ぐ）。

## 世界
- 空：太陽高度・方位から夕焼け・薄明・夜（星・月）・朝焼けを計算するドーム。太陽と月は方向光（影付き）。夜も脚と接地点が判別できる明るさに露出を保つ。
- 地面：乾いた土と草。押し潰しマップ（休んだ形・蹄・周辺の倒れ草）を地面と短草の頂点シェーダが読む。朝は露（未接触の草が銀色）で寝跡が浮く。
- 草：休み場所の短草、周囲の中丈の株、観察者と休み場所の間の背の高い草むら（切れ目つき、手前の株は指で曲がりバネで戻る。観察者が通ると左右へ分かれる）。

## 既知の課題
- 描画負荷が高め（三角形 約35万＋影）。古い iPad では自動で解像度と草密度を下げるが、実機での体感速度は未確認。
- 立ち上がり・伏せの中間姿勢は関節目標の補間で作っているため、実写と比べると一部の中間（後脚の折り畳み途中）がやや単純。
- 寝跡は縦向き画面では小さめ（観察者が踏み込み・立ち上がって見下ろす演出で補っている）。
