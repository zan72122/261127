# よるの すいそう（261127-52）

夜のリビングで、空っぽのガラス水槽を「光の筋が差し、魚が泳ぐ青緑の小さな水の森」に変えていく、文字のない指1本ゲーム。

## 流れ（場面内の順番は自由・失敗なし）
0. **したく**（引きの全身・後ろ姿）: 床の長靴をタップ → 足元へ飛んで履く。女の子をタップ → 袖がくるくる腕まくり。両方そろうと「よーし」と跳ねて水槽へ寄る。
1. **砂と水草**: トレイの道具（砂カップ・小石カップ・流木・水草）。押している間だけカップが傾いて砂が流れ落ち、落ちた所にだけ積もる。長く押すほど高い山になり、安息角（約32°）で崩れて自然な円すい形になる。小石は1粒ずつ転がって止まる。流木・水草はタップした所に置かれる（同じ所を何度も＝茂る）。砂がおよそ半分・流木1・水草3でゴール（引きで拍手）。
2. **水**: じょうろを押している間だけ水位が上がる。水が砂に直接当たる最初ほど白く濁り（濁りはその場所から広がる）、待つと**底から**澄んでいき、澄むほど光の筋が差す。半分まで来ると**ママがやらかす**：大きなじょうろで勢いよく注いで水があふれ、ガラス前面とキャビネットを伝って床に水たまりが広がる（「あっ」「あらら」）。カメラが床に寄り、娘がタオルでなぞった所だけ水が吸われ、タオルは濡れて色が濃くなる。ここでじょうろを床に使うと、ママが「あれ？」→「ふふっ」と笑う（違う物への反応）。拭き終わると「ありがとう」。自分であふれさせても同じように拭ける。澄んだらゴール。
3. **魚**: 魚の入った袋3つ（オレンジのプラティ型・テトラ型・ゼブラダニオ型）。タップすると手が袋を水面へ運び、傾けて放す。魚は水草の間を回遊し、テトラは群れる。貝殻・エアストーン（泡）を置いた所に魚が寄り、指でガラスをとんとんすると近づく。全部放すと拍手、その後はずっと遊べる。

ヒント: 次に使う道具がトレイでときどき揺れ、4秒触らなければ白い手が指さす。ルールは水槽の横（縦画面では上の壁）のクレヨン絵カード1枚（砂と草→じょうろと水→魚）。

## 写実のためにしたこと
- **素材はすべて PBR**。テクスチャ生成 API はクレジット切れだったため、`tools/gen_tex.py` で写真風テクスチャを手続き生成（すべて周期的でつなぎ目なし）。砂は Voronoi の粒（色の違う石英・長石・黒い粒、粒ごとのドーム形状と隙間の陰）、床はオーク板（板ごとに木目をずらす・溝）、ウォルナット、漆喰、リネン・コットン・デニムの織り目（糸の太さむら）、ニットの編み目、ラグ、流木、亜鉛メッキ風の金属傷、タオルのループ、肌の毛穴、髪の束、ゴム。各素材に **色・法線・ORM（AO/粗さ/金属）** の3枚。
- **主役の変化をシミュレーションで描く**: 砂は 118×70 の高さ場（頂点変形＋断面スカート）。量が少ない縁は砂粒テクスチャでまばらに抜け、水に浸かった所だけ暗く・つやが出る。濁りは水槽前面の 40×24 の場（注いだ x 位置から湧き、横と上に拡散、底ほど速く沈む）を水のシェーダーで乳白に混ぜる。床の水たまりは 64×46 の濡れ地図で、濡れた所だけ色が濃く・粗さ0.04・法線が平らに、タオルでなぞった所だけ戻る。
- **写実の切り口**: 水面の波（周期的な高さ場）を光子マップして作ったコースティクス模様を、水中の砂・小石・流木・水草・魚にだけ投影（2層をずらして min 合成＝網目が揺れる）。水槽のガラス角は、ポスト処理で側面ガラスの全反射を近似し、内側の景色が角で二重に映る（水中は強く、水上は弱く）。水本体は透過（屈折率1.33）で中が少し寄って見え、緑がかった減衰。ガラスはフレネルで縁ほど映り込み、板の断面は緑色。
- **照明**: 2700K 相当のフロアランプ（スポット・柔らかい影）＋上向きの間接光、半球光、暖色の部屋を元にした PMREM 環境マップ、水槽の LED（7000K 相当・影付きスポット）とその漏れ光、手元の補助光。ACES フィルミック＋sRGB。夜の雰囲気は色温度と背景で出し、水槽と手元は明るい露出。
- **カメラ**: 人の目の高さ付近、縦横比に応じて 34〜54° の縦画角（35〜50mm 相当）、場面ごとに自動で寄る/引く。ポスト処理で軽い被写界深度（奥を主にぼかす）とビネット。
- **人**: カプセル人形にしないため、手・腕・体は SDF（なめらかな結合）からサーフェスネッツでメッシュ化。指は3節＋親指・指の付け根の関節の盛り上がり・母指球、頂点色で爪・指先の赤み・手のひらの明るさ。肌は sheen と赤みの回り込みで簡易的な皮下散乱。袖は折り返しの厚みとしわを持つ布の筒。女の子の全身は引き・後ろ姿のみ（低いポニーテール、ニット、デニムのスカート、タイツ、長靴）。顔の大写しは作らない。反応は跳ねる・拍手・腕を上げる＋短い声。
- **粒子**: 砂粒・水滴・しぶき・泡・漂う微粒子は大きさと速さをばらつかせ、光の中で見えるようにした。

## 技術メモ
- three.js r180（`lib/` に同梱、CDN 不使用）。ES モジュール: `main.js`（描画基盤・部屋・水槽・道具）→ `game.js`（流れ・入力・カメラ・ヒント）、`tank.js`（砂・水・魚・植物）、`people.js`/`sdf.js`（人）、`audio.js`（効果音と声はすべて WebAudio 合成。音声ファイルなし）、`tex.js`（テクスチャの後読み。届くまでは平均色で表示）。
- 重さ対策: 最初は指さしの手1種だけ作り、他の手の形はアイドル時に1つずつ生成。2秒平均で 34ms を超えると解像度を段階的に下げる。透過パスは0.6倍解像度。ランプの影は引き/床の場面だけ更新。
- 確認用 URL: `?scene=scape&fill=1` / `?scene=water&level=0.4` / `?scene=floor` / `?scene=fish&allfish` / `?hand=grip`。
- index.html は通常の head/body。playlog の script タグ挿入を妨げる処理はしていない。
