# どうぞ、どうぞ！おにんぎょうのおうち（261127-62）

写実寄り3Dの人形の家で、人形や小物を自由につまんで運んで置く、言葉のいらないおもてなし遊び（toy_sandbox）。

- 起動: `games/261127-62/index.html`（単一ファイル。CSS・JS・three.js・テクスチャ・音はすべて実行時に生成／同梱。外部通信なし）
- 公開時は既存の playlog ロガー（`gf-playlog.js`）が配信パイプラインで追記される前提。ゲーム側はロガーと別のキー（`gf261127-62.house.v1`）だけを使う。

## 遊び（文字なし）

| さわる | かえってくる反応 |
| --- | --- |
| 人形の胸をつまむ | すぐ数cm浮き、足・髪・スカートが遅れて揺れ、真下の影が薄く広がる。離すと小さく沈んで止まる。短いタップでもこちらを向いて笑う |
| 人形を玄関へ／扉をさわる | 扉が蝶番で開く。扉の内と外に人形がいると向き合って会釈「トン・チリン」。外と内は入れ替え自由 |
| 靴（左右別々）を靴棚へ | 棚に左右そろって並び、足は靴下姿。足元へ戻すとその側の足に履ける |
| 人形を椅子の近くへ | 広めに吸着して膝を曲げて着席し、向かいの相手を見て微笑む。つまむと即立ち上がる |
| ケーキ・クッキーを手元／口元へ | 手に持つ。口元では咀嚼音と満足顔。食べきると少しして元の場所に補充される |
| 持たせた人形ごと別の人形へ | 相手が手を伸ばして受け取り、喜ぶ。渡し返しも同じ操作 |
| ポットをカップの上へ | 傾いて注ぎ、水面が上がる。ポットは空にならない |
| カップを持った人形どうしを近づける | 乾杯して二音が重なる。続けるほど音が育つ |
| 花飾り・リボンを壁の留め具／扉／テーブル／頭へ | その場所だけ光と花びら。近くの人形が見て拍手し、顔を見合わせる |
| 寝室のベッドへ人形、布団をかける | 横になり、布団で目を閉じる。隣に別の人形を置くと寝顔をのぞいて小さく手を振る。布団を外すと起きる |

- 来客: 帽子の友達（手土産の箱）→ しばらくしてリボンの友達（花束）が玄関の外に来てノックする（遊んだ時間の目安：約2.5分／約5.5分。外が空いていて扉を開けると少し早まる）。手土産は誰かに渡すか、タップで開き、中のクッキーを誰にでも渡せる。
- 組み合わせごとに会話のような身ぶりと音（呼びかけと返事）が変わる。
- 誘導: 次の誘いを一つだけ、柔らかい光と小さな跳ねで示す。無操作約4秒で一度だけ、手が人形を椅子までつまんで運ぶ実演（触れたら即中止、配置は確定しない）。
- 縦画面では居間と寝室を、画面端に人形や小物を運ぶ／端をタップすることで行き来する（端がほんのり光る）。横画面では両室が一度に見える。

## 保存（端末内のみ）

人形の位置・着席・寝ている場所、左右の靴、手持ち、飾り、カップのお茶、手土産の開封、来客の進み具合を `localStorage` に保存。初回・復元・破損（JSON不正、型違い、範囲外、存在しない場所）・保存拒否（SecurityError）・容量不足（QuotaExceeded）のいずれでも遊びは続く。

## ファイル

- `index.html` … 配布物（ビルド済み単一ファイル）
- `src/` … ソース（three.js r187 を esbuild で tree-shake して埋め込み）
  - `main.js` レンダラ／カメラの自動フレーミング／ループ（rAFのみ、非表示で停止）
  - `doll.js` 人形（顔は手描きキャンバス＋3Dの寝目・まぶた、樹脂の毛束、布の服、スカートのモーフ、リジッドスキニングで描画呼び出しを削減）
  - `room.js` 家（壁紙・腰壁・木目床・扉・窓・家具・寝室・屋根、静的メッシュは材質ごとに結合）
  - `items.js` 小物とスロット（手・足・頭・靴棚・留め具・ケーキ・皿・箱・ベッド）
  - `game.js` 入力（Pointer Events、一本指、キャンセル・画面外対応）、つまみ判定、運ぶ・置く
  - `behave.js` 人形の姿勢・視線・表情・身ぶり
  - `rules.js` 相互作用（挨拶、手渡し、食べる、注ぐ、乾杯、飾り、靴、ベッド、来客、会話）
  - `guide.js` 誘導（一度に一つ）と手の実演
  - `audio.js` Web Audio 合成（ゆるい二拍子の呼びかけと返事、効果音）
  - `save.js` 保存と復元
- `tools/build.mjs` … `cd tools && npm install && node build.mjs` で `index.html` を再生成

### この検証で見つけて直した点
- 乾杯がドラッグ中に何度も連続発生 → 判定距離とリセット距離にヒステリシスと2.5秒の間隔を追加
- 持たせた人形ごと相手へ運んでも渡らないことがある → 運ぶ人形が相手の方を向く＋置いた瞬間にも受け渡し判定
- テーブル越しの奥の椅子に座らせにくい → 画面上の見た目の近さでも椅子に吸着
- 外の人形を斜めに室内へ戻すと扉の外に引っかかる → 開いた扉の前では入口へ寄せて通す
- 注いだ直後のポットが近くの人形の手に入ってしまう → 注いだ直後2秒は手に入れない
- 胸元へ運んだ食べ物を即食べてしまう → 口元が胸元より近い時だけ食べる（受け取りと食べるを区別）
- テーブルの上に人形が立ってしまう → 近くの空いた椅子へ、なければテーブルの脇へ
