# ぬったら ほんもの（261127-55）

5 歳の子が iPhone / iPad で指 1 本で遊ぶ、文字のない 3D の遊び。
春の昼下がりの公園の舗道に白いチョークで描かれた車と小舟。**指で塗った所だけ**チョークの粉がきらっと光り、本物の塗装の鉄板・ゴムのタイヤ・ガラス・板張りの船体・帆布に変わっていきます。

## 遊びの流れ（3 場面）

0. **帽子とチョーク**：ベンチの上の麦わら帽子がかすかに光る → 触ると女の子がかぶって跳ねる（この子の手が自分の指になる）。チョーク箱を触ると始まる。
1. **車**：パパが先に「パパもかくよ！」と後ろのタイヤを雑に四角く塗ってしまう（やらかし）。
   女の子（プレイヤー）が車体・窓・前のタイヤを塗る。塗った所から順に浮き彫りがせり上がり、全部そろうと車が地面から起き上がり、エンジン音で一周する。
   後ろのタイヤが四角いと **がたがた跳ねて** 走る → パパ「あれれ？」→ 立っている車のタイヤを直接塗ると、塗った分だけタイヤの形が丸く育つ → なめらかに一周して完成。
   （先に女の子が四角の外側を塗って丸くしておけば、最初から上手に走る。）
2. **小舟**：船体と帆を塗る → 水たまりが池に広がり、小舟が起き上がって浮かぶ（しぶき・波紋）。
3. **自由に描く**：舗道に自分で線を描くと、丸→ボール／四角→段ボール箱／長い線→はしご の下絵になる。中を塗ると本物になって置かれる（ボールは跳ね、箱はふたが開く）。
   ベンチのパパが吹き出しの絵で欲しい物を伝え、違う物ができると「あれ？」と首をかしげてから「それもいいね！」と拍手。車・小舟は触ると走る／帆走する。ここは好きなだけ遊べる。

チョーク箱（左下）の色を替えると、その色で塗った所だけ車や舟の色が変わる（1 台の車がまだら・ツートンにもなる）。
塗る場所・量・順番・色・タイヤの形が毎回違うので、同じ遊びでも仕上がりが毎回変わります。
失敗やゲームオーバーはありません。数秒触らないと白い手が次の場所を指し、塗る場所のチョーク線がかすかに光ります。

## 主役の「ビフォー → アフター」の作り方

- **塗りマップ（GPU レンダーターゲット）**：舗道 8m×4m を 2048×1024 の 2 枚の RT で持つ。
  `tChalk` = チョークの色と量（乗算済み）、`tReal` = R:本物になった量 / G:絵が起き上がって抜けた印 / B:白い下絵の線。
  指の動きをスタンプ（ざらざらのブラシ）として RT に描き、0.3 秒遅れて「本物」側にも描く（その瞬間にキラッと粒が出る）。
- **部品のマテリアル改造**（`js/mask.js`）：車体・タイヤ・ガラス・船体・帆・ボール等のシェーダーが、自分の頂点の設計座標で塗りマップを引く。
  本物になっていない所は捨て（下の地面のチョークが見える）、境目は**チョークの粉の色・粗さ 1・金属感ゼロ・クリアコートなし**から、
  **鏡のようなクリアコート塗装／ゴム／ガラス**へ、ざらついたノイズのしきい値でなめらかに切り替わる（写実の切り口）。
- **平面から立体へ**：寝た状態の車は浅い浮き彫り（塗った量で最大 0.2 倍の厚み）。全部そろうと奥行きが 1 倍に戻りながら、下側の縁を軸に 90° 起き上がる。
  影はシャドウマップで、浮き彫りの厚みに合わせて伸びる（影の描画にも同じマスクを掛けているので、塗っていない所は影も落ちない）。
- **タイヤの形＝塗った形**：タイヤの塗り格子から角度ごとの半径を求め、タイヤとホイールの頂点を変形。
  走る時は回転した輪郭の最下点から車体の高さと傾きを出すので、四角いタイヤは本当にがたがた跳ねる。
- 地面のチョークは、アスファルトの高さ（AO）で**骨材の山に先に粉が乗り、くぼみは強くこすった時だけ埋まる**。粉の所は粗さ 1・法線を平らに。

## 写実のためにしたこと

- **素材はすべて PBR**（MeshStandard / MeshPhysical）。テクスチャは `tools/gen_tex.py` で numpy から生成（FFT ノイズでタイル可能、文字・人物・ロゴなし）。
  アスファルト（骨材とバインダー・くぼみ）、芝、桜の樹皮（横向きの皮目）、木目、車の塗装（ゆず肌＋細かい傷）、タイヤのトレッド、金属のヘアライン、
  ニット・デニム・綿の織り目、肌の毛穴、髪の流れ、麦わらの編み目、段ボール、ゴムの粒、チョークの粉…に **色・法線・粗さ/AO（ORM）** を持たせた。
  車体はドアの継ぎ目・ノブ・給油口を法線と AO に描き、クリアコート側に別のゆず肌法線。ガラスは高反射のクリアコート。
- 大きな平面のタイル感は、低周波のムラ地図を 2 段で掛けて消した。
- **照明**：春の 14 時ごろ。太陽は高度約 48°、約 5500K のやや暖かい白、PCF のふちがぼやけた影。空のグラデーションと遠景の木々を
  PMREM で HDR 風の環境マップにし、反射と環境光に使用。弱い半球光で影側が黒くつぶれないようにした。ACES フィルミック＋sRGB 出力。
- 接地の暗がり：車・人の下にやわらかい接地影、地面テクスチャの AO、車体下部の AO。
- **カメラ**：短辺で 38°（35mm 相当）の画角。高さは 1〜1.5m 前後（人の目の高さ）で、遊ぶ所を斜めに見下ろす（真上のミニチュア視点にしない）。
  ごく弱い被写界深度（深度バッファで遠景だけ少しぼかす後処理。重い端末では自動で切る）。
- **大きさは実物どおり**：子ども用の車 長さ 1.36m・幅 0.74m、タイヤ径 31cm、小舟 1.2m、女の子 110cm、パパ 約 180cm、ベンチ座面 44cm、チョーク 7.5cm。
- **人**：カプセルを組まず、胴は楕円断面の回転体、腕・脚は関節を通る曲線に沿って太さが変わる管（毎フレーム曲げる）。
  袖にはひじのしわ、スカートはひだ、ボブの髪は頭の形に沿う殻＋毛先の束。顔は大写しにせず、引き・後ろ姿・横向きで、反応は跳ねる・拍手・首をかしげる と短い声。
- **手と腕（いちばん大きく映る）**：手のひらは母指球のふくらみと拳の山を持つ超楕円体、指は 3 関節の管で関節がふくらみ先が丸い。
  爪は指先の甲側だけを覆う光沢の板。皮ふは毛穴の法線＋シーン（赤い散乱の近似）。袖口はニットのリブとしわ。チョークをつまむ持ち方。
- **粒子**：キラッ（加算・またたき・大きさばらばら）、チョークの粉（重力で落ちる、色付き）、水しぶき、花びら（ひらひら回転して落ち、地面にも散る）。
- 夜や暗い場面はない（昼の屋外）。露出は遊ぶ所（舗道と車）が明るく見えるように合わせた。

## 技術メモ

- three.js r170 を `lib/` に同梱（外部 CDN なし）。ES モジュールを `js/` に分割。
- 最初は中立色の 1×1 テクスチャで描き、画像が届いたら同じ Texture に差し込む（シェーダーの作り直しなし）。初期場面に要る物を先に、
  車・舟・ボール用の重い物は後から読む。
- 端末の速さを 2.5 秒ごとに測り、30fps を割りそうなら 被写界深度オフ → 解像度倍率を下げる → 影の解像度を下げる の順で軽くする。
- 音はすべて Web Audio で合成（チョークのこすれ・キラッ・エンジン・がたん・水・ボールのぽよん・小鳥）。声は端末の読み上げで短いひとこと（文字は画面に出さない）。
- `tools/check_refs.py`：コードと HTML が参照するローカルファイル（スクリプト・テクスチャ）を一覧にして 1 つずつ実在確認する。
- 公開時に入る `gf-playlog.js` を邪魔しないよう、index.html は普通の head / body のみで、head を書き換えたり別のログ送信をしたりしない。
