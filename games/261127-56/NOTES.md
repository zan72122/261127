# ろくろで うつわ（games/261127-56）

冬の午後、薪ストーブの燃える陶芸小屋。濡れた茶色い土を、ろくろの上で自分の指で器にし、
釉薬の桶にくぐらせ、窯で焼くと、くすんだ粉っぽい釉薬がガラスのようなつやに変わる。
文字なし・指 1 本（タップ／長押し／なぞり）。

## 流れ（場面ごとに小さなゴール）
0. **エプロン**：引きの全身・後ろ姿の女の子。壁のペグのエプロンをタップ → 飛んで着る → 跳ねて喜ぶ → ろくろへ。
   壁には「土 → ろくろ → 桶 → 窯 → つやつやの器」だけを描いた黒板の看板（ルールは絵だけ）。
1. **ろくろ**（場面1）：指が女の子の右手（左手は反対側から支える）。
   - 真ん中を長押し → 穴があき、長く押すほど深く広く（底で押し続けるとお皿の方向へ広がる）
   - 外側を下からなぞり上げる → 壁が薄く高く（花びん）。上の方を押し続ける → すぼまる（つぼ）
   - 口縁を外へなぞる → 開く（鉢・お皿）／押し下げる → 低く厚く
   - 水の鉢・スポンジ → 指が濡れ、しずくが垂れ、触った所だけつやが出る。乾いた指は効きが弱い
   - 一度形になると **パパが「はやく まわそう!」とレバーを倒しすぎて器がぐにゃっと倒れる**。
     女の子がたたいて丸め直し、もう一度作る。切り糸が光ったらタップで完成。
   - 乾燥は早回し：口縁から先に白っぽく乾く（湯気が上がる）。
2. **釉薬**（場面2）：さかさまの器を指でつまんで動かし、青・飴・白の桶へ。浸した場所と長さで厚みが変わり、
   横に動かすと傾いて斜めの線、2 つの桶で重ね掛けも。引き上げると口縁へ向かって垂れの筋がつき、
   つまんでいた指の跡は釉薬がつかない。窯が光ったらタップ。
3. **窯 → 食卓**（場面3）：扉を閉める → ダイヤル → のぞき穴が赤→橙→黄白、うなり → 扉をあけると器はまだ赤く熱い。
   冷めるにつれて色とつやが現れ、ピキッという音とともに貫入のひびが広がる（触った所からも広がる）。
   食卓では椿を挿す・スープをよそう・みかんをのせるを好きなだけ。形に合わないものを入れると
   パパとママが首をかしげて「あれ?」→ でも拍手。布の上の新しい土をタップすると、できた器は棚に残って最初から。

## 主役の変化（ビフォー → アフター）の作り方
- **形**：器を「外側の半径 Ro(y)・内側の半径 Ri(y)・高さ H・底 yF」で持ち、指が当たった帯（外／口縁／内／底）、
  押した長さ、なぞる向きと速さで少しずつ変える。土の体積は毎フレーム保存（削った分は口縁と高さへ）。
  同じ操作でも、押す順番・時間・水の量で毎回違う形になる。メッシュは毎フレーム回転体として作り直す。
- **ろくろ目**：指は止まり土が回るので、触っている間だけ (角度, 断面の弧長) のキャンバスに溝と両わきの盛り上がり、
  砂粒が引きずる細い筋を描く。上下に動かすと螺旋になる。これを法線の傾きとして使う。
- **水・どろ**：同じ座標系のキャンバスに「濡れ」と「スリップ」を描き込み、濡れた所だけ色が濃く、粗さが下がり、
  クリアコートが乗る。時間とともに乾いて戻る。
- **回転中のぶれ**：土の粒のテクスチャを円周方向に 5 回ずらして平均（シャッター 1/60 秒ぶんのモーションブラー）。
  こねたままの凸凹と芯ずれは、触るほど消えていく（センタリング）。
- **釉薬**：器の表面を (u, v) = 128×256 の格子にし、各点の世界座標が液面より下で桶の中なら厚みを足す。
  焼く前は粉っぽく粗い（粗さ 0.97・法線強め・くすんだ色）。焼成後は厚みで濃淡（青は薄いと灰青・厚いと瑠璃、
  飴は薄いと金茶・厚いと黒褐）、ろくろ目の山では薄く谷では濃くなる「釉切れ」、重なりは緑や水色の斑、
  粗さ 0.07 + クリアコート。貫入は 3D ボロノイの境界線を、タップと自然発生で広がるマスクの中だけ出す。
- **窯**：焼成中は器が黒体放射のような橙に光り、開けてから冷めるにつれて色が見えてくる。

## 写実のためにしたこと
- 素材はすべて MeshStandard / MeshPhysical。床板・壁板・れんが・鋳鉄・ヘアライン金属・メリヤス編み・平織り・
  ネル・コーデュロイ・肌・髪・粘土の粒・漆喰を **numpy で生成した写真風 PBR テクスチャ**（色・法線・AO/粗さ/金属）で作成
  （`tools/gen_textures.py`、FFT の周期ノイズなので継ぎ目なし。文字・人物・ロゴなし）。単色ベタの大きな面はない。
- 人と手はカプセルの組み合わせではなく、**SDF をなめらかに溶かし合わせ Surface Nets でメッシュ化**（`tools/build_bodies.mjs`）。
  指は 3 節・指節の膨らみ・中手骨の筋・母指球・爪（別素材のつや）・指の腹。袖口は編み目つきの折り返し。
  距離場からの頂点 AO を焼き込み、指の間や袖口の暗がりを出す。布・肌は三方向投影で織り目・毛穴を貼り、
  シーン（Sheen）で布の柔らかい照り返し。手には触った分だけ泥が付く。
- 顔の大写しは作らない：女の子は後ろ姿と手、パパは引きの横姿と腕、食卓の家族は胸から下（被写界深度でぼける）。
  反応は跳ねる・拍手・うなずき・首かしげと短い声（端末の音声合成、文字は出さない）。
- 光：冬の低い西日（約 4500K、VSM のやわらかい影が床に窓の形を落とす）、雪の照り返しの青白い空の光、
  3000K の作業灯（ろくろの真上）、食卓の灯り、ゆらぐ薪ストーブの火、焼成中の窯の光。
  HDR 風の環境マップ（明るい窓・暖かい壁・火・電球を持つ部屋を PMREM に通したもの）で反射。
  床置きの物には接地の影（AO）を足した。暗い画面にしない露出（場面ごとに露出を調整）。
- 仕上げ：HDR（半精度）で描いて、ほんの少しの被写界深度（ピントは今触る物）→ ACES フィルミック → sRGB、
  ごく弱い周辺減光とフィルムの粒。カメラは人の目の高さ近く、35〜45mm 相当（短辺 24mm 換算）、手持ちのわずかな揺れ。
- 粒子：窓の外の雪（大きさ・速さ・揺れがばらばら）、窓の光の中だけ光るほこり、しずく、釉薬のしずく、湯気。

## 重さ
- three.js r170 を同梱（`vendor/`、外部 CDN なし）。最初はテクスチャ 64px の仮ノイズで描き、写真風テクスチャは後から 3 本並列で読み込んで差し替え。
- 人と手のメッシュは量子化したバイナリ（`mesh/*.bin`）。iPhone では解像度 1.6 倍まで・MSAA 2。
  fps が 34 を下回ると自動で解像度を下げる。太陽の影は 6 フレームに 1 回だけ更新。

## ファイル
- `index.html`（通常の head / body。importmap で `vendor/three.module.min.js`）
- `js/main.js` 進行・カメラ・入力・ろくろ・手 / `js/clay.js` 器の形と素材シェーダー / `js/glaze.js` 釉薬と窯 /
  `js/table.js` 食卓 / `js/room.js` 小屋と光 / `js/people.js` 人・手・エプロン / `js/post.js` 被写界深度とトーンマップ / `js/audio.js` 合成音
- `tex/` 生成テクスチャ、`mesh/` 生成メッシュ、`tools/` それらを作るスクリプト

## 判断の記録
- 画像生成 API（Stability）はクレジット切れで使えなかったので、写真風テクスチャはすべて numpy の手続き生成にした。
- 土の形は最初、断面の密度格子を指で押しのける方式を試したが、土が霧のように散ったり穴が戻ったりして
  きれいな器にならなかった。そこで「外径・内径・高さ・底」の壁モデルに切り替え、押した帯ごとの規則
  （外を押す＝細く高く、内を押す＝ふくらむ、口縁を外へ＝開く、真ん中の長押し＝穴があいて広がる）で動かした。
  土台は細くならない・口縁だけ太らない、などの制約で、子どもが適当に触っても器らしい形に落ち着く。
- 人の顔は作り込まない方針（人形っぽさを避ける）。食卓の家族は胸から下が見える高さにカメラを置いた（縦画面も）。
- 窯の操作盤は扉の下部、乾燥の早回しは口縁から乾く順に。釉薬の桶から窯へは、釉薬をかけた器を「トン」と軽くたたく。
- 確認：iPhone 縦横（390×844 / 844×390）、iPad 縦横（820×1180 / 1180×820）の実画面をヘッドレスで撮って見直し、
  袖口の切り口が見える・道具が画面外・窯の操作盤が画面外・スープが白く飛ぶ、などを直した。
- `thumb.png` は実際の画面（焼き上がった花びんに椿を挿した食卓、ピントは器）から作成。
- 参照ファイルの確認：index.html / js から参照するローカルファイル 63 件（three.js・js モジュール・テクスチャ 46 枚・
  メッシュ 7 個）を一覧にして 1 つずつ存在確認し、欠けは 0。ヘッドレスでの通し確認でも 404 なし。
