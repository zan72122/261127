# びんのなかのもり（びんの中の小さな森）— 制作メモ

## 作ったもの
晩秋の朝、窓辺の机の上の大きなガラスびん。中には乾いて茶色く縮れた苔、小さな家、小さな線路と列車。
白衣を着た女の子の「手」になって、霧吹き・小石・小枝・ふた・スポイト・虫めがねで小さな森を育てる。
文字・数字は画面に一切出さない（タイトルタグのみ）。

| 場面 | 触ること | 小さなゴール |
|---|---|---|
| はじまり | 帽子掛けの白衣をタップ → 白衣が女の子に飛んで着替える | 研究員になる |
| 1 霧吹き | 押しているあいだ霧が出る。霧が落ちた所だけ苔が水を吸う。途中でパパが霧吹きを強くしすぎて水びたし → スポイトで吸ってコップに捨てる | 苔の6割が緑・水たまりが消える |
| 2 小石・小枝・ふた | なぞった線に小石が並ぶ／小川をまたいでなぞると小枝の橋がかかる／ふたを閉めると内側が曇って結露し、指でなぞった線だけ晴れる | 小道＋橋＋ふた＋曇りふき |
| 3 虫めがね | 当てた所が拡大して見える。家に当てると灯りがともり、列車に当てると出発 | 灯り＋出発 → その後は全部の道具で好きなだけ |

- 変化は触った場所・長さ・回数・道具の分だけ起きる（全面一斉切替なし、毎回仕上がりが違う）。
  - 苔: 128×128 の湿り気マップ。霧の粒子1つ1つが落ちた所に湿り気を足す。湿り気は毛細管的にゆっくりにじむが乾かない。上限を超えると水たまり（浅水流シミュレーション、低い所＝小川へ流れる）。
  - 小石／小枝: なぞった軌跡を補間して一定間隔で置く（線路の上は避けて踏切にする）。小川の横断を検出すると橋。
  - 曇り: 内壁の曇りテクスチャ（微細な霧）＋水滴の高さテクスチャ。ふいた線の両脇に押し寄せた水滴が並び、重い水滴はたれて筋を残す。
- パパのやらかし: 霧吹きを強くしすぎ（ジェット）→「おっとっと」→ 女の子がスポイトで立て直す。水たまりに霧吹きを向けると「あれ?」と手が首をかしげるように揺れる。
- ルールは絵の看板1枚（茶色い苔＋霧吹き→緑、小石の道→家、虫めがね→列車）。
- 次に触る物はうっすら光って揺れ、数秒触らないと白い手が指さす（なぞる所はなぞる動き）。
- 喜びは顔でなく体で：場面達成でカメラが引き、女の子（後ろ姿）が跳ねて拍手、パパがうなずく。声は短い「やったー!」など（端末の音声合成、無い端末では無音）。効果音はすべて WebAudio 合成。

## 写実のためにしたこと
- **素材はすべて PBR**（MeshStandard / MeshPhysical）。色・法線・粗さ・AO の地図を Python で手続き生成（`tools/gen_textures.py`）。
  - 苔は「上から見た苔の芽を数万本、葉を1枚ずつ描く」ミニレンダラーで、乾いた（縮れて閉じた茶色）と濡れた（星形に開いた緑）を**同じ配置で**2枚描き、高さバッファから法線と AO を作った。
  - オーク材（板目・導管・放射組織・ワニスの細かい傷）、しっくい、塗装木部（欠け）、土の地層（軽石・炭・砂利・細根）、小石、樹皮、綿ツイル（白衣）、リネン（カーテン）、ニット、ネルシャツ、デニム、肌の毛穴、髪の流れ、金属の傷、陶器、コルク、羽目板、屋根板。
  - 当初は画像生成 API で写真テクスチャを作る予定だったが、接続先のクレジットが残っていなかったため全部手続き生成にした。
- **触った所だけ見た目が変わる仕組み**: 湿り気・水深・小川マスクを1枚のデータテクスチャにまとめ、
  - 地面: 色（茶→くすんだ緑→みずみずしい緑→濡れて濃い）、粗さ、頂点の膨らみ（乾くと縮み、濡れると約3.5mm ふくらむ）を湿り気で切り替え。
  - 苔の芽（約5,000〜8,500本のインスタンス、1本35枚の葉）: 頂点シェーダーで湿り気を読み、乾くと葉が茎に巻きつき縮れ、濡れると星形に開いて伸び、色が変わる。逆光の朝日が薄い葉を透ける表現（透過光）付き。水に沈むと寝る。
  - 葉先の水滴: 湿り気が高い所だけ出る球体インポスター。縁の暗さ・窓の映り込み・下側の屈折・朝日のきらめきを描く。
  - 水たまり: 水深で高さと不透明度が変わる鏡面の水面＋さざ波。
- **ガラス**: 反射だけを加算し、背景は少しだけ減衰させる薄いガラスのブレンド（フレネルで縁が光る）。中の土の地層がガラス越しに見える。曇りは前方散乱で朝日に光り、水滴は窓と太陽を映してきらめく。
- **照明**: 11月下旬の朝。窓の後ろ左上の低い太陽（約4000K、暖色）、窓からの冷たい空の光、カメラ側の白い壁からの照り返し。小さな HDR 部屋（明るい窓・太陽円盤・暖色の壁）を PMREM にした環境マップ。VSM のふちがぼやけた影、物の下の接地 AO。ACES フィルミック＋sRGB。
- **大きさは実物どおり**: びん直径32cm、苔の芽の高さ約5mm、小石4〜13mm、Zゲージ相当の線路（軌間6.5mm）、女の子110cm、パパ178cm（スツールに座る）、机の高さ72cm。カメラは約38mm相当（長辺基準）、女の子の目の高さ付近から見下ろす。窓の外は事前にぼかした庭（被写界深度）。
- **人物**: カプセルの組み合わせを避け、符号付き距離場の骨・肉・服・髪をなめらかに合成 → マーチングキューブ → 間引き（`tools/gen_meshes.py`）。服のしわ・袖口の折り返し・スカートのプリーツ・ニットの畝・髪の束をジオメトリで作り、スキニングで動かす。顔の大写しは作らず、全身は後ろ姿、画面の主役は手元。
- **手**: 最も大きく映るので、5歳児の手の比率（ふっくらした指・母指球・爪の領域）で作り、指を3関節ずつ骨で曲げる（握る・つまむ・指さす・持つ・引き金を引く・スポイトを押す）。白衣の袖は綿ツイルの織り目とねじれじわ。腕はびんの口の上から入る（ガラスを突き抜けない）。
- **粒子**: 霧の粒は大きさ・速さ・寿命をばらつかせ、ヘニエイ–グリーンスタイン位相関数で逆光の朝日に光らせる。大粒の水滴は別の見た目。家の煙突ではなく列車の蒸気、窓辺のほこり用の種類も用意。

## 重さへの配慮
- 外部 CDN なし（three.js r170 を `lib/` に同梱）。最初の画面に要るテクスチャ（部屋・人物・苔の低解像度版）だけ待ち、残りは 4×4 の中間色の仮画像で描画しながら後から差し替え。苔の高解像度は最後。
- 人物メッシュは位置と UV を16bit 量子化。
- 虫めがねのレンダーターゲットは持っている間だけ描く。苔の芽は影を落とさない（地面が落とす）。
- フレームレートを見てピクセル比を下げ、それでも重ければ苔の芽の本数を減らす自動調整。
- iPhone 実機での fps は未計測（ヘッドレス環境の SwiftShader でしか描画できないため）。調整は上記の自動処理に任せている。

## 確認したこと
- iPhone 縦（390×844 / iPhone 13 エミュレーション）・横（844×390）、iPad 縦（834×1194）・横（1180×820）でスクリーンショットを撮り、道具の配置・カメラの寄り・腕の入り方・袖の穴・パパの頭が切れる構図などを直した。
- 全フロー（白衣→霧吹き→パパ→スポイト→小石・橋→ふた→曇りふき→虫めがね→自由）を自動操作で通した。
- コードから参照するローカルファイル60件がすべて実在することを1つずつ確認（`tex/*.jpg`、`mesh/people.*`、`lib/three.module.min.js`、`js/*.js`）。

## ファイル
- `index.html` — 通常の head/body。`js/main.js` を module で読むだけ。
- `js/` — `main.js`（流れ・入力・カメラ・道具）、`moss.js`（苔と水のシミュレーション）、`jar.js`（ガラス・曇り・ふた）、`props.js`（道具・家・線路・列車・看板）、`people.js`（手・人物）、`room.js`（部屋と光）、`particles.js`、`audio.js`、`assets.js`。
- `tex/`, `mesh/` — 生成物。`tools/` — 生成スクリプト（`python3 tools/gen_textures.py`, `python3 tools/gen_meshes.py`。numpy, Pillow, scikit-image, scipy, fast-simplification）。
- `?dbg=s1|s2|s3|free` で各場面から始められる（開発用）。
