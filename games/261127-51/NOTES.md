# なぞの あしあと（261127-51）

5歳向け・文字なし・指1本。雨上がりの昼、古いタイルの台所で空っぽのクッキーびんの「犯人」を探す。
主役の素材は **黒い粉・金の粉（刷毛）と紫の光（UVライト）**。触った所だけ、見えなかった跡が浮かぶ。

## 流れ
1. **導入**: 女の子（後ろ姿）がびんをのぞいてしょんぼり。テーブルの帽子をタップ → 帽子と虫めがねが飛んできて「たんていさん」に（跳ねて喜ぶ）。以後カメラは彼女の目線（約1.1m）になり、指＝彼女の手。
2. **場面1 粉と刷毛**: 黒／金の粉の缶をタップで刷毛に粉をつけ、びんとタイルをなでる。なでた所だけに粉の膜が付き、1回目は灰色のもや＋うっすら、何度もなでるともやが払われ指紋の渦や肉球が黒（金）くくっきり浮かぶ。粉が尽きると毛先が白っぽくなり、缶がヒント。浮かんだ跡をタップすると虫めがねで拡大。肉球の跡を全部出すとゴール。
3. **場面2 紫のライト**: 床を照らした所だけ、子犬の足あとが青白く光る。照らした跡はかすかに光り続け、点々と道になる（戸棚 → テーブルの奥 → ラグ → ソファの座面 → カーテン）。8割照らすとカメラが次の区間へ。
   - **パパのやらかし**: パパが粉の詰め替え缶を持って手伝いに来て落とす → 粉が舞い、くしゃみ3回で全身粉まみれ、よろよろ歩いて靴下の跡だらけ。娘（後ろ姿）がパパと床を刷毛で払うと、払った所から粉が取れる（頂点ごとの粉量）。きれいになるとパパがグッド、ライトに戻る。
4. **場面3 カーテンの裏**: ふくらんで揺れるカーテンを横になでると、なでた所から布がたたまれて開く。鼻にクッキーくずの子犬が見つかる（気まずい顔 → キャンキャン）。ボールとほねクッキーの手渡し（ボールだと「あれ？」と首をかしげてから喜ぶ）。
5. **自由あそび**: 床やガラス戸をタップすると手形がぺたん（黒／金の粉を選べる）。子犬が寄ってきて粉の足あとを残す。トレーのライトを選ぶと、押した手形や足あとが全部紫の光で浮かぶ。失敗なし、ずっと遊べる。

ルールの看板は、タイルに貼った子どものクレヨン画1枚（刷毛→肉球、ライト→光る足あと、カーテンの裏に犬）。数秒触らないと白い手袋の指がタップ／なぞりを示す。

## 写実のためにしたこと
- **レンダリング**: three.js r180（同梱）。HDR（半精度）MSAA ターゲット → 自作ポスト（被写界深度・ACES フィルミック・sRGB・うっすら周辺減光とフィルム粒子）。PMREM 環境マップは「この部屋の簡易版（明るい窓・電球）」から生成。
- **光**: 窓から差す 5600K 前後の太陽（PCF のふちがぼやけた影、壁は厚い外殻を持ち窓からだけ光が入る）＋パティオ戸からの 7000K の空の光＋テーブル上の 3000K ペンダント＋半球光。暗い場面を作らない露出。日だまりの中だけ光るほこり（影を受けるパーティクル）。
- **素材**: すべて MeshStandard/Physical。テクスチャは Python で手続き生成（ベースカラー・法線・AO/粗さ/金属のパック）: 釉薬の貫入とすり減りのあるチェッカータイル、目地の汚れ、白いサブウェイタイルのふくらみ、長い繊維と年輪と板の継ぎ目の木目、塗装木、リネンの織り（スラブ糸）、ブークレのソファ、綿ツイル（コート）、ツイード（帽子）、ニット、デニム、ローレットのアルミ、傷のあるブリキ、肌の毛穴。雨粒の付いた窓ガラス（法線とマスク）。
- **人物・手・犬**: SDF（距離関数）を Python で組み、マーチングキューブ → 間引き → Taubin 平滑化。頂点に SDF から焼いた AO と色（指先・関節の赤み、爪のマスク）。表面の細部は三平面マッピングで布・肌の法線を載せる。手（5歳の手の寸法、握り／パーの2ポーズ）は一番大きく映るので最も細かく、肌は sheen で赤みのある縁。子犬は 14 層のシェル法で毛、目はクリアコート、湿った鼻。顔の大写しは作らず、人物は後ろ姿・引き・手で見せる。
- **ビフォー→アフター**: 触った所にだけ GPU の塗りマップ（レンダーターゲット）へ刷毛の筋とムラ付きのスタンプを加算。表面シェーダが粉の膜（灰色のもや、金は金属・低粗さ）を、潜在指紋メッシュが「粉の量でもや→くっきり」の隆線と凹凸（微分バンプ）を描く。UV の跡はスポットの円錐内だけ発光し、照らした分だけ残光。パパの粉は頂点属性、手形・足形はインスタンスのデカール（凹凸つき）。
- **粒子**: 粉は対数正規の大きさ・個別の抵抗と重力・ゆらぎ。光を受ける板ポリ（MeshStandard、影を受ける）で、金は金属として光る。
- **大きさ**: ドア約2.2m、台所カウンター92cm、女の子110cm、パパ178cm、子犬の座高約30cm。カメラは 30〜38mm 相当、目線は約1.0〜1.3m。

## 判断メモ
- Stability AI はクレジット切れで使えず、テクスチャは全部手続き生成にした（文字・ロゴ・人物なし）。
- 初回表示を速くするため、各テクスチャは 1/4 サイズを先に読み、表示後に高解像度へ差し替える。重い法線は 512〜1024px に抑えた（合計約11MB）。
- iPhone で 30fps を保つため、フレーム時間を見て描画解像度を自動で下げる。
- 音はすべて WebAudio で合成（刷毛のこすれ、粉のぽふっ、発見のチャイム、ライトのうなり、くしゃみ、子犬の声、雨上がりのしずく）。
- `tools/` に生成スクリプト（gen_textures.py / gen_meshes.py / gen_prints.py）を残した。
