# しょうぼうし ほうすいくんれん（261127-53）

5歳向け・文字なし・指1本の Web ゲーム。夕焼けの消防訓練場で、炎に水を当てて「熱いものを冷ます・煙を晴らす」。
主役の素材は **炎・水・湯気**（と、濡れて夕日を映す鉄）。

## 遊びの流れ（場面ごとに小さなゴール、順番は場面内で自由）
0. **身じたく**：ラックの防火衣とベンチのヘルメットをタップ → 飛んできて女の子が着る（セーターとポニーテール → 紺の防火衣・銀の反射帯・革手袋・シコロ付きヘルメット）。両方着るとジャンプして出発。
1. **放水**：指で触れた所へ、女の子が構えたノズルから放物線の水が飛ぶ。炎4つ（2階の窓2つ・燃焼パン・パレット）。
   - 当てた所だけ変わる：鉄板の塗りマップ（濡れ＝暗く・つやが出る、すす、熱）に水滴が着弾ごとに描き込まれ、たれた水が筋になって下へ流れる。乾いても「しっとり」が残る。
   - 当てた長さで 炎 → くすぶり（赤く小さく、灰色の煙）→ 白い湯気 → 濡れた黒い鉄（湯気の名残がしばらく立つ）。熱い鉄に当たった瞬間は湯気が爆ぜ、ジュッと鳴る。
   - 4つ消すと女の子がジャンプ、パパが拍手、カメラが引いて湯気の立つ濡れた家を見せる。
2. **煙の部屋**：コンテナの中は煙（3D 格子で煙をシミュレーションし、画面の奥行きに沿ってレイマーチ）。
   - 窓のシャッターを触ると巻き上がって夕日が差し込み、そこから煙が抜ける。送風機を触ると回って風が起き、開いた窓へ煙が流れる。指でなぞると手であおいだ所が少し薄くなる。どれをどれだけやったかで晴れ方が毎回違う。
   - 奥にくまのぬいぐるみ（ほかに木のおもちゃの消防車とボール）。パパの頭の上の絵の吹き出しが「くま」。違う物を渡すとパパは首をかしげて「あれ？」→ うなずいて受け取る。くまを渡すとパパが抱きしめて大喜び。
3. **はしご車と虹**：夕日を一度見てから振り返る（夕日を背にする）。
   - **パパのやらかし**：パパのホースが手から抜けて暴れ、パパがずぶぬれ（防火衣が濡れて暗く・つやが出て、すそから滴が落ちる）。光るホースを触ると女の子がつかんで押さえ、パパが水を止めてブルブル。
   - リモコンではしご車を操作：はしごを長押しで起こして伸ばす（結果は残る）。空を触るとはしごの先から放水、ターンテーブルがその方向へ回る。
   - 水しぶきが霧になり、**太陽と反対側の点から42°の所にある霧だけ**が虹色に光る（主虹＋うすい副虹、内側が少し明るい）。水を当てた方向に虹が現れて動く。ここは終わりなしで好きなだけ遊べる。

ヒント：触れる物はふちがほのかに光り（フレネル状の脈動）、4秒触らないと白い手が次に触る所を指す。失敗やゲームオーバーはない。
ルールの看板：炎→ノズル→湯気の3コマの絵だけの看板を訓練場に立てた。

## 写実のためにしたこと
- **素材**：すべて MeshStandard / MeshPhysical。ベース色・法線・ORM（AO/粗さ/金属度）の3枚1組を `tools/maketex.py` で生成（FFT のスペクトル合成とラップするボロノイで継ぎ目なし）。鉄板（傷・さび・雨だれ）、コンクリート（骨材・気泡・ひび）、防火衣の綾織り、革（細かいシボとしわ）、赤い塗装（ゆず肌と小傷・クリアコート）、木目、ぬいぐるみの毛足、ホースの織り、ゴム、砂利、室内の塗装壁。単色ベタの大面はなし。
  - 生成 AI（Stability）はクレジット不足で使えなかったので、写真の代わりに手続き生成で「写真風」の凹凸と色むらを作った。
- **変化は描き込みで**：家の正面と地面に CPU 側の塗りマップ（濡れ・すす・熱）を持ち、着弾点にだけスプラッシュを描く。シェーダで「濡れ＝アルベド半分・粗さ0.1前後」「すす＝暗く粗く」「熱＝ごく弱い赤い発光」。たれ（drip）が下へ流れて筋を残す。
- **照明**：高度約11°の夕日（暖色の平行光、2048の PCF 影、ぼけた縁）、空ドーム（地平の橙・反太陽側のピンクの帯と地球の影・夕焼け雲・遠くの林のシルエット）を PMREM で環境マップ化、半球光は弱め。炎ごとに揺らぐ点光源で周りを橙に照らす。部屋は作業灯（スポット、影あり）・裸電球・窓からの夕日で暗くしない。
- **ポスト処理**：HDR（HalfFloat・MSAA）→ 深度による控えめな被写界深度 → 明るい所だけのブルーム → ACES フィルミック → sRGB → 周辺減光と微細な粒子ノイズ。
- **接地**：人・トラック・家の足元にぼかした接触影、マテリアルの AO。
- **人**：カプセル・円柱を組まない。胴は断面が楕円で縦のひだ・腰のしわ・前立ての溝がある1枚の布、腕と脚は肩–ひじ–手首／股–ひざ–足首を通る**1本の連続した管を毎フレーム作り直す**（2ボーンIK）ので関節の継ぎ目がない。袖・すそ・ひざに反射帯。5歳児（110cm・頭身大きめ）と大人（178cm）で寸法を別に持つ。顔は大写しにせず、後ろ姿・横・引き。反応は跳ねる・拍手・うなずき・首かしげ・ブルブルと短い声（フォルマント合成）。
- **手と腕（いちばん大きく映る所）**：ガントレットが袖の上にかぶさる構造用グローブ。指は3関節×4本＋親指（握り・指差しを関節角で変える）、甲のナックルパッド、反射テープ、手首ベルト、細かいシボの革。1人称の場面では女の子の目の高さから自分の腕と手袋が見え、部屋では指の方へ手を伸ばし、はしご車ではリモコンを握る。
- **粒子**：水は速度方向に伸びる滴（大きさ・寿命ばらばら、時々きらめく、虹の角度なら色づく）。煙と湯気は4種の柔らかい塊を回転・拡大させ、太陽と近くの炎の光で CPU ライティングし、奥から順に描く。
- **大きさ**：コンテナ 6.06×2.44×2.59m、ドア約2m、女の子110cm、パパ178cm、はしご車約10m。カメラは人の目の高さ付近、縦画面でも横の画角を保つよう FOV を合わせ、縦長では少し引く。

## 判断の記録
- 「夕日に向けて放水すると虹」は物理的には逆（虹は太陽を背にした側に出る）。写実を優先して「夕日を一度見せてから振り返り、夕日を背にして放水」にした。夕焼けの光そのものは虹の場面でも全体を照らす。
- パパのやらかし（ホースが暴れる）は場面2から場面3の冒頭へ移した（はしご車のホースとつながり、ずぶぬれの変化が夕日でよく見えるため）。
- 炎は家の大きさに比べて小さめ（窓の中・燃焼パン・パレット）。家は無人の訓練用コンテナ。逃げ遅れた人や苦しむ表現はなし。
- 重さ：iPhone で 30fps を保つため、描画解像度をフレーム時間で自動調整（0.75〜2倍）、塗りマップの GPU 転送は最大 12Hz、煙シミュは 30Hz、粒子数に上限。外部 CDN なし（three.js r170 を `lib/` に同梱、テクスチャは JPG/PNG 4MB 程度）。
- 最初の画面は夕焼け色のローディング（しずく）を出し、テクスチャがそろってから（最長7秒）表示して、白いのっぺりした面を一瞬でも見せない。
