# あついガラス つめたいガラス — 作業メモ

5歳の娘が iPhone / iPad で指1本で遊ぶ、文字のないガラス工房ゲーム。
元ネタは「熱い対冷たい」の回。対決ではなく、**1つの素材（溶けたガラス）が熱から冷たさへ変わる時間そのもの**を遊びにした。

## 流れ（3場面＋着がえ）
0. **着がえ**：夜の工房。壁の板に掛かった厚い手袋と保護めがねをタップ → 女の子の手と顔へ飛んでいき、女の子が拍手・うなずき。両方そろうと作業台へ。
1. **作業台（手元の一人称）**：竿の先で橙に光るガラス玉。
   - 長押し（玉・竿・ブローホース）＝息を吹き込む。押した時間だけふくらむ。熱い所ほど先に伸び、竿の付け根は首になる。
   - なぞる＝手袋の手が持つジャックが指先について玉を引き伸ばす（頂点の変形。触った場所だけ）。
   - 色の粉の皿をタップ／長押し＝皿が玉の下へ上がる。竿は回り続けるので、当てたタイミングと長さで色の帯や渦が描き込まれる（256×128 の塗りテクスチャに粒状に描き、熱いうちは少しなじむ）。熱いあいだ色は暗い帯として見え、冷めると色ガラスとして現れる。
   - 形ができると竿の首が光る → タップで「コンコン、カキン」と切り離し。吹いた物はコップ（口が開き、底が平らになる）、吹かない物は玉になる。3個作ると次へ。
   - **パパのやらかし**：ふくらませすぎると、割れずにシャボン玉のように薄く虹色になる。パパが近づきすぎて眉毛がちりっ（煙・眉が縮む）。光るタオルをタップすると娘がパパのおでこに冷たいタオルを当て、パパは親指を立てる（ふくらませすぎなくても1個目の後に必ず1回起きる）。
2. **冷ます場所**：熱いトレーに3個。ドラッグで女の子がトングで運ぶ。
   - 水の桶に入れる＝ジュッと湯気、浸かった部分だけ一気に冷えて **クラックル（ひび模様）** が入る（実在の技法）。
   - 冷ましの棚に置く＝ゆっくり 赤 → 暗い赤 → 透明な青・緑へ。冷める途中でチリチリ鳴る。
   - 全部冷めて棚に並ぶと朝へ。
3. **朝の窓辺（ずっと遊べる）**：朝日が差す。木箱から窓台へドラッグで並べると、ガラスを通った色の光が窓台と床に落ちる。置く場所で模様が変わり、タップで回すと光の形も変わる。光の中のほこりが舞う。

正解はあるが失敗なし。次に触る所は白い輪がかすかに光り、5秒触らなければ白い手が指さす。ルールは壁の絵看板1枚（手袋とめがね → 光る玉 → 桶と湯気 → 窓と色の光）。

## 写実のためにしたこと
- **素材はすべて PBR**：Python で写真風テクスチャを手続き生成（コンクリート・赤レンガ・耐火レンガ・オーク・パイン・ヘアライン鋼・黒皮鉄・焼け色の竿・スエード・ジャージ編み・デニム・帆布・革・タオル地・漆喰・色ガラスの粉・肌・クラックル・水面）。各セットに色／法線／AO・粗さ・高さ（ORM）を持たせ、継ぎ目なしにタイル。木目は板の長手方向に沿うよう UV を自動で向ける。
- **人と手袋は SDF から作った有機的な形**：丸い円錐と楕円体のなめらかな合成に、服のしわ（関節の折れじわ・ノイズ）、手袋の縫い目と指の付け根のしわ、カフの折り返しを入れてマーチングキューブ化 → 削減 → SDF 勾配で滑らかな法線、凹みの AO を頂点に焼き込み、骨の重みを付けてスキニング。布は三平面投影＋高さからのバンプ（骨が動いても模様が泳がない）。カプセル人形にしない。
- **手が一番大きく映る**ので手袋を最も細かく（1.3mm 格子）作り、指は3関節で握る。袖口の編み地も見える。
- **熱いガラス**：頂点ごとの温度 → 黒体放射の色と強さ（黄橙 → 赤 → 暗赤 → 消える）。熱いうちは透過を下げて内側から光り、熱のゆらぎ（画面のかげろう歪み）、ブルーム、玉の中の渦の明暗、近くの道具を照らす橙の点光源。冷めると透過・屈折（IOR 1.5、厚みで色が濃くなる減衰色）になり、中の気泡が屈折して見える。薄くなりすぎると虹色の薄膜（iridescence）。
- **照明**：夜は電球色の作業灯（スポット・ソフト影）＋炉の揺らぐ橙＋室内の照り返しを HDR 風の環境マップ（PMREM）で。暗くしない露出に。朝は 9月末 8時ごろ（高度約38°）の東からの太陽、窓枠の影が床に落ちる。ACES フィルミック＋sRGB 出力、わずかなビネットとフィルム粒子。
- **色の光**：太陽から見た正射影カメラでガラスの色と集光（中心が明るい）をレンダーターゲットに描き、床と窓台に乗算投影。窓台の影の線より奥にだけ落とす。
- **カメラ**：人の目の高さ近く、縦画面でも 35〜50mm 相当の画角に収まるよう距離を自動調整。わずかな被写界深度。顔の大写しはしない（着がえは後ろ姿寄り、パパは引きの上半身）。
- 接地の暗がり（接地影デカール）、炉・作業台・桶・棚にも足元の AO。
- 粒子（湯気・煙・色粉・火花・ほこり）は大きさ・寿命・速度をばらつかせ、光で見えるように。

## 構成
- `index.html` … 通常の head／body。`<meta name="robots" content="noindex">`。外部 CDN なし。
- `js/three.module.min.js`（r170 同梱）、`RoundedBoxGeometry.js`
- `js/core.js` テクスチャ（低解像度で先に出し後から高解像度へ差し替え）、PBR／三平面材質、後処理
- `js/world.js` 工房、`js/glass.js` ガラス、`js/figure.js` 人と手袋、`js/fx.js` 粒子、`js/audio.js` 音（全部 WebAudio 合成）、`js/game.js` 進行
- `tex/` 生成テクスチャ、`mesh/` 生成メッシュ、`tools/` 生成スクリプト（`python3 tools/gen_textures.py`, `python3 tools/gen_meshes.py`）

## 重さ
- 画素比は最大 1.75、2秒ごとに fps を見て 32fps 未満なら下げる（さらに重ければ被写界深度を切る）。
- 影の再描画は、その時間帯に効いている光だけ（夜は作業灯、朝は太陽）。
- 最初は 128px のテクスチャで描き、最初の1フレーム後に高解像度を1枚ずつ読み込む。

## 判断の記録
- 写真テクスチャの生成 API はクレジット不足で使えなかったため、全テクスチャを Python の手続き生成にした（文字・人物・ロゴなし）。
- 顔の写実は難しいので、着がえは後ろ姿寄り、冷ます場面は机の向こうの小さめの姿、窓辺は後ろ姿。反応は跳ねる・拍手・うなずきと短い声（言葉ではない母音の合成音）。
- 熱いガラスに手で触れる表現はしない。作業台はジャック（はさみ状の道具）、冷ます場所はトング越し。手で持つのは冷めた後の窓辺だけ。
- 完成前に iPhone 縦横・iPad 横のスクリーンショットと、着がえ→吹く・色・切る→パパの失敗→桶と棚→朝までの自動プレイで見直し、塗りが白飛びした熱いガラス、床の黒い点（AO の強すぎ）、画面外の色皿、木の幹のようだったパパの前掛けなどを直した。
- `thumb.png` は実際のゲーム画面（朝の窓辺：冷めたコップ・クラックルの青・窓台に落ちる緑の光）。
